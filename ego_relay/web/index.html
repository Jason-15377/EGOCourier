EGO Courier 日志对齐 · 异常检测

日志导出（设备配网 → 拉取 → 一键导入）

① Wi-Fi 配网（BLE）

扫描蓝牙 → 选择设备 → 填 Wi-Fi 名称/密码（各 ≤32 字节）→ 配置并等待设备加入局域网，成功后自动回填设备 IP。需电脑蓝牙已开启。

② SSH/SFTP 一键导出

用配网回填/手填的设备 IP + SSH 账号，拉取设备上的 app 日志与固件日志，拉完自动导入分析。
