## EGO Courier v1.1.0

本版把「日志分析」整体换成 **EGOChecker 分析引擎**（源码内嵌在 `ego_checker/`），并把分析流程收敛成「选目录 → 分析 → 一份 HTML 报告」。同时新增**定时分析**和**会话记录**两个现场常用能力，日志导出与分析的联动也做了简化。

### 一、分析引擎重构

- 一次分析读取所选目录下的**全部**采集数据：
  - CSV：相机 / IMU / 夹爪等时间戳 CSV（`*_pts.csv`、`camera_*.csv`、`imu*.csv`…）；
  - 视频：目录内的 MP4 与 MCAP 录制（相机视频流、传感器流，SEI 时间戳提取）；
  - 音频：WAV 文件及配套 CSV；
  - 元数据：`meta_*.json`。
- 检查项：相机帧数对齐、帧间隔波动、同行对齐、相机同步、IMU 同步、夹爪同步、RGB 丢帧、IMU 丢帧/倒退、音频时长与包完整性、元数据完整性；跨录制段做边界比对。
- 结果**只输出一份自包含 HTML 报告**：不再写会话数据库、不再生成结果 CSV 或额外证据目录；报告内联 CSS/JS，可直接分发。
- 移除 `matplotlib`，依赖总量约 150MB；新增 `lz4`、`zstandard` 以读取 MCAP 压缩流。

### 二、日志分析页

- 顶部可在**目录分析**与**定时分析**之间切换。
- 参数按业务分组：会话与文件（单设备/多设备、落盘格式、配对等级、并发）、检查项（Depth / SEI / 音频 / 元数据）、阈值（自适应或固定输入）、帧截取（不同步帧 / 同步帧截取）。
- 后台线程运行，实时日志 + 进度，支持**暂停 / 停止**；停止时仍生成部分报告。
- 分析完成后可「打开 HTML 报告」「打开输出文件夹」；双击结果单元格查看异常明细。
- 分析完成/停止弹窗列出问题 Part（异常 / 执行异常 / 未验证）及失败的检查项，可「定位异常 Part」在结果表中选中并在 HTML 报告中跳到对应明细行；报告顶部同时提供「问题 Part 快速定位」链接。
- 内存按滑动窗口分段释放，常驻内存最多 3 段，不随录制段数增长（开启帧截取时退回全量驻留以保证截帧结果一致）。

### 三、定时分析（新增）

- 支持「每天 HH:MM」或「仅一次 YYYY-MM-DD HH:MM」。
- 定时数据目录是**列表**：可添加多个目录，按列表顺序逐个分析，每个目录写入独立时间戳输出目录。
- 到点自动用保存时的**参数快照**启动分析；支持错过补跑（默认 2 小时内），程序启动或电脑睡眠唤醒后按真实时间判断。
- 「启用定时分析」勾选时自动保存当前目录列表与参数；「保存定时设置」可更新规则/参数快照；「暂停定时」立即停用但保留配置。
- 配置保存在 `data/analysis_schedule.json`；同一时间只允许一个 EGO Courier 实例执行定时（`QLockFile`）。
- 定时依赖 EGO Courier 进程保持运行（窗口可最小化，不要退出）。

### 四、会话记录（重做）

- 每次分析完成写一条记录到 `data/history/sessions.json`（原子写入，损坏时自动归档），只存**指向**报告与数据目录的路径和统计，不复制报告内容。
- 按结论 / 设备 / 数据目录筛选；可回看详情、Part 明细、重跑分析、删除记录。
- 报告或数据目录被移动后，记录保留并标灰，不会悄悄消失。
- 定时任务与手动分析共用同一套结果表和 HTML 报告；批次完成显示成功目录数。

### 五、日志导出页

- 一键导出 / 打包完成后，自动把本次导出目录预填到「日志分析」页，切过去点「开始分析」即可。
- 新增「先压缩再导出 zip」：导出目录保留（仍可直接分析），同时生成同名 zip 便于对外发送；取消或失败时目录与 zip 一起清理。
- 新增「只导新增日志」：仅对 app/SDK 本机日志生效，按上次成功导出的结束时刻只拉新增部分；手机日志和设备固件日志仍全量拉取。记录按 EGOViewer 根目录隔离，存于 `data/export_incremental.json`，可「清除记录」恢复全量。
- 移除旧的「导出后自动导入分析 / 自动生成 HTML 报告」选项——分析统一在「日志分析」页执行，避免导出流程里嵌入一套已不存在的会话数据库逻辑。

### 六、清理与修复

- 删除旧的会话数据库、Trace 查询、结果 CSV 导出、`video_analyzer` 独立脚本与 CLI 入口。
- 修正 `ego_checker/media/video.py` 帧截取分支中未定义的 `_log` 调用（时间序列不一致时会抛 `NameError`）。
- 移除仍调用已删除函数 `sftp_pull.import_pulled` 的旧 SFTP 导出页（功能已由「日志导出」页覆盖）。
- 修正日期时间浮层的类型注解与若干失效导入。
- 统一「选择设备 / 固件设备」列表的勾选与行选中样式，避免 Windows 11 原生深蓝实心块与界面其它勾选框不一致。

### 验证情况

- 全量 **194 项单元测试通过**（`python -m unittest discover -s tests -p "test_*.py"`），新增 `test_analysis_schedule.py`（定时触发/补跑/持久化/损坏恢复）、`test_history_store.py`（历史登记簿写入/读取/损坏归档）、`test_export_state.py`（增量起点读写与越界保护）、`test_mobile_fw_picker.py`（固件设备勾选/自动扫描）与 `test_report_problem_parts.py`（问题 Part 汇总与定位）。
- 全部源码 `compileall` 通过；`pyflakes` 无 undefined name。
- GUI 与 `ego_checker` 全模块在无头模式下可导入。

> **未覆盖**：真实设备的 BLE 配网、固件实时拉取、adb 拉取依赖现场环境；建议在桌面环境用一段真实录制目录跑一次完整分析，确认 HTML 报告与「会话记录」联动。
